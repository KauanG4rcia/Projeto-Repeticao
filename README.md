## Projeto de Repetição
Esse projeto utiliza linguagem python 🐍;  </br>
Ele simula uma pesquisa de opinião simples, pedindo nome, idade e opinião do usuário. Esse projeto utiliza a condicional de repetição **for**, visto que é uma pesquisa com um número limitado de usuários. Comandos básicos como *If*, *Elif* também foram utilizados.
